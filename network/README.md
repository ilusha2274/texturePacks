# Общий пак сети HYPETRAIN

Один пак на все сервера (lobby, speedrun, spy, hideandseek, traitor, maniac). Пока у каждого режима
был свой пак, при каждом переходе клиент менял набор паков и перезагружал ресурсы (красный экран
Mojang). С одним паком Velocity видит, что пак с этим sha1 у игрока уже стоит, и не пересылает его -
перезагрузка только один раз, при входе в сеть.

## Как обновить

1. Правь текстуры в папках режимов (`lobby/`, `maniac/`, `hideandseek/`) - как раньше.
2. `./network/build.sh` - соберёт `network/hypetrain-pack.zip` и напечатает sha1.
3. Закоммить и запушь репозиторий.
4. В `server.properties` **всех шести** Paper-серверов впиши новый `resource-pack-sha1` (URL и
   `resource-pack-id` не меняются) и перезапусти их. sha1 обязан совпадать везде - иначе на переходе
   снова будет перезагрузка.

## Что тут своего

- `assets/hypetrain/font/fade.json` + `textures/font/fade.png` - символ `` шрифта
  `hypetrain:fade`: чёрный прямоугольник больше любого экрана. Им GameOrchestratorPlugin плавно
  затемняет экран при переходе между серверами.

## Компромиссы при склейке

- **Голод**: из пака маньяка берутся только прозрачные `food_*_hunger`; плагин маньяка вешает
  скрытый эффект Голода, поэтому шкала там не видна. В других режимах она пропадает, только пока у
  игрока настоящий эффект Голода (гнилая плоть и т.п.).
- **Riptide**: вихрь трезубца прозрачный во всех режимах, а не только в прятках.
