# Общий пак сети HYPETRAIN

Один пак на все сервера (lobby, speedrun, spy, hideandseek, traitor, maniac). Пока у каждого режима
был свой пак, при каждом переходе клиент менял набор паков и перезагружал ресурсы (красный экран
Mojang). С одним паком Velocity видит, что пак с этим sha1 у игрока уже стоит, и не пересылает его -
перезагрузка только один раз, при входе в сеть.

## Как обновить

1. Правь текстуры в папках режимов (`lobby/`, `maniac/`, `hideandseek/`) - как раньше.
   Оружие дуэлей — в `weapons/`: модель правится в `weapons/flintlock.bbmodel`, потом
   `python3 weapons/bbmodel_to_java.py` пересоздаёт `weapons/assets` (положение в руке — словарь
   `DISPLAY` в этом скрипте).
   Предметы «Предателя» — в `traitor/`: модели `traitor/knife.bbmodel` (нож) и
   `traitor/syringe.bbmodel` (шприц) в формате Java Block/Item, положение в руке — вкладка Display
   в Blockbench. `build.sh` сам запускает `traitor/build_models.py`, который пересоздаёт
   `traitor/assets` (иконка шприца в инвентаре — адреналин Маньяка с зелёной жидкостью).
   `traitor/build-test.sh` + `serve-test.sh` — тестовый пак с мака без правки общего.
2. `./network/build.sh` - соберёт `network/hypetrain-pack.zip` и напечатает sha1.
3. Закоммить и запушь репозиторий.
4. В `server.properties` **всех шести** Paper-серверов впиши новый `resource-pack-sha1` и поменяй
   хвост `?v=` в `resource-pack` (скрипт печатает готовую строку), `resource-pack-id` не меняется.
   Перезапусти их. sha1 обязан совпадать везде - иначе на переходе снова будет перезагрузка.

   Зачем `?v=`: raw.githubusercontent кеширует файл до 5 минут после пуша. По старому URL клиент
   получит старый zip, sha1 не совпадёт - «не удалось загрузить ресурспак». Новый `?v=` - новый URL,
   мимо кеша.

## Что тут своего

- `assets/hypetrain/font/fade.json` + `textures/font/fade.png` - символ `` шрифта
  `hypetrain:fade`: чёрный прямоугольник больше любого экрана. Им GameOrchestratorPlugin плавно
  затемняет экран при переходе между серверами.

- `assets/minecraft/textures/gui/title/background/panorama_*.png`, `menu_background.png` — чёрные, и
  пустые строки `connect.reconfiguring` / `multiplayer.downloadingTerrain` в `lang/`. Это фон и
  надписи экранов «Перенастройка» и «Загрузка территории», которые клиент сам показывает при смене
  сервера через Velocity (убрать их нельзя). С ними экраны просто чёрные и сливаются с затемнением.
  Главное меню не задевают: серверный пак выгружается при выходе с сервера.

## Компромиссы при склейке

- **Голод**: из пака маньяка берутся только прозрачные `food_*_hunger`; плагин маньяка вешает
  скрытый эффект Голода, поэтому шкала там не видна. В других режимах она пропадает, только пока у
  игрока настоящий эффект Голода (гнилая плоть и т.п.).
- **Riptide**: вихрь трезубца прозрачный во всех режимах, а не только в прятках.
