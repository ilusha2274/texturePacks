# Текстур пак «Маньяк»

Ставится только на сервер `maniac` (`server/maniac/server.properties`, `require-resource-pack=true`).

- **Шкала голода скрыта**: прозрачные спрайты `assets/minecraft/textures/gui/sprites/hud/food_*.png`.
  Голод в игре используется только чтобы блокировать спринт (выносливость — в полоске опыта).
- **Свои предметы**: плагин вешает на лут выживших, предметы классов и хук маньяка модели
  `hypetrain:maniac/<id>`.

## Как добавить свою текстуру

Положи PNG 16×16 в `assets/hypetrain/textures/item/maniac/` с таким именем:

| Файл | Предмет |
|---|---|
| `medkit.png` | Аптечка |
| `adrenaline.png` | Адреналин |
| `fuel.png` | Канистра бензина |
| `gas_wrench.png` | Газовый ключ (в руке держится как инструмент) |
| `sword.png` | Меч (в руке как инструмент) |
| `crossbow_arrow.png` | Арбалет заряженный (выдаётся всегда заряженным) |
| `crossbow_standby.png` | Арбалет пустой (почти не виден — после выстрела пропадает) |
| `defibrillator.png` | Дефибриллятор медика (предмет класса) |
| `maniac_hook.png` | Хук маньяка (в руке как инструмент) |

### Динамит (блок)

Динамит в мире — блок, который код заставляет «дышать», дымить фитилём и вспыхивать после закладки.
Свои текстуры (в ту же папку): `dynamite_side.png` (бока, без неё — ванильный TNT),
`dynamite_top.png` (верх с фитилём), `dynamite_bottom.png` (низ); без верха/низа берутся от TNT.

**Анимация**: кадры 16×16 столбиком в одном PNG (16 × 16·N, например 16×64 = 4 кадра). Скорость —
`frametime` (тиков на кадр) в готовых `dynamite_side.png.mcmeta` / `dynamite_top.png.mcmeta`;
`interpolate: true` плавно перетекает между кадрами — так делается мерцающий фитиль и тлеющие бока.

Потом `./build.sh` — он сам переключит предмет на твою текстуру (пока PNG нет, отдаётся ванильная
модель-заглушка), соберёт `maniac-pack.zip` и напечатает sha1. Дальше: закоммитить и запушить
репозиторий, вписать sha1 в `resource-pack-sha1` у `server/maniac/server.properties`, рестарт `maniac`.

Броню не рисуем — она кожаная, крашеная случайным цветом.

## Исходник текстур

Текущие PNG нарисованы скриптом `draw_textures.py` (пиксель-арт кодом, без зависимостей):
`python3 draw_textures.py assets/hypetrain/textures/item/maniac /tmp/preview.png`. Скрипт
**перезаписывает** PNG — если перерисовал что-то руками, не запускай его для этой папки.
