# Текстур пак «Маньяк»

Ставится только на сервер `maniac` (`server/maniac/server.properties`, `require-resource-pack=true`).

- **Шкала голода скрыта**: прозрачные спрайты `assets/minecraft/textures/gui/sprites/hud/food_*.png`.
  Голод в игре используется только чтобы блокировать спринт (выносливость — в полоске опыта).
- **Свои предметы**: плагин вешает на лут выживших модели `hypetrain:maniac/<id>`.

## Как добавить свою текстуру

Положи PNG 16×16 в `assets/hypetrain/textures/item/maniac/` с таким именем:

| Файл | Предмет |
|---|---|
| `medkit.png` | Аптечка |
| `adrenaline.png` | Адреналин |
| `fuel.png` | Канистра бензина |
| `gas_wrench.png` | Газовый ключ (в руке держится как инструмент) |
| `dynamite.png` | Динамит |
| `sword.png` | Меч (в руке как инструмент) |
| `crossbow_arrow.png` | Арбалет заряженный (выдаётся всегда заряженным) |
| `crossbow_standby.png` | Арбалет пустой (почти не виден — после выстрела пропадает) |

Потом `./build.sh` — он сам переключит предмет на твою текстуру (пока PNG нет, отдаётся ванильная
модель-заглушка), соберёт `maniac-pack.zip` и напечатает sha1. Дальше: закоммитить и запушить
репозиторий, вписать sha1 в `resource-pack-sha1` у `server/maniac/server.properties`, рестарт `maniac`.

Броню не рисуем — она кожаная, крашеная случайным цветом.
